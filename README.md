# Mint-Track - Expense Tracker

A simple and powerful web-based expense tracking application that helps you take control of your personal finances.

## 🌟 Features

- **Easy Expense Tracking**: Quickly add and categorize your expenses
- **Visual Analytics**: View spending patterns with beautiful charts
- **Budget Management**: Set budgets and track your progress
- **Mobile Friendly**: Responsive design works on all devices
- **Privacy First**: All data stored locally in your browser
- **Export Data**: Download your expense data for analysis

## 🚀 Live Demo

Visit the live application: [Mint-Track GitHub Pages](https://your-username.github.io/mint-track)

## 📱 How to Use

1. Open the application in your web browser
2. Start adding expenses using the form
3. View your spending summary and recent transactions
4. Export your data for backup or analysis
5. Access Terms & Conditions and Privacy Policy for legal information

## 🔒 Privacy & Security

Mint-Track is built with privacy as a core principle:
- All data is stored locally in your browser
- No data is transmitted to external servers
- No tracking or analytics
- Complete control over your financial information

## 🛠️ Technical Details

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: Browser localStorage API
- **Icons**: Font Awesome
- **Responsive**: Mobile-first design
- **No Backend**: Fully client-side application
